# Guía de Estilo: NutriFit Systems

## 1. Objetivo Estético
El diseño debe proyectar una imagen de **clínica premium, profesionalidad y seguridad tecnológica**. Se busca una estética minimalista con mucho espacio negativo ("aire") para evitar la saturación visual. El estilo debe ser moderno y humano, transmitiendo confianza a través de formas suavizadas y una paleta de colores inspirada en la salud y la naturaleza.

## 2. Paleta de Colores

| Elemento | Hexadecimal | Uso |
| :--- | :--- | :--- |
| **Fondo Principal** | `#FAFAFA` | Fondos de sección y áreas generales (Blanco roto). |
| **Fondo Secundario** | `#E8F5E9` | Tarjetas, estados hover y secciones de soporte. |
| **Acento Suave** | `#81C784` | Bordes, separadores, etiquetas e iconos. |
| **Primario** | `#2E7D32` | Botones de acción (CTA), estados activos y resaltados. |
| **Texto y Footer** | `#1A3622` | Títulos, párrafos y fondo del pie de página. |

## 3. Tipografía
Se han seleccionado fuentes que combinan una estructura espaciosa con terminaciones redondeadas para reforzar la claridad y cercanía.

* **Títulos (H1, H2, H3):** `Lexend`
    * *Estilo:* Estructura ancha y poco común.
    * *Propósito:* Aporta máxima claridad y un toque de innovación tecnológica.
* **Cuerpo de texto:** `Nunito Sans`
    * *Estilo:* Terminaciones redondeadas y trazos limpios.
    * *Propósito:* Mantiene el tono humano y profesional, garantizando una lectura descansada en textos largos.

## 4. Componentes y UI
* **Botones:** Esquinas redondeadas para coherencia con la tipografía.
* **Tarjetas:** Sombras muy sutiles o bordes finos en `#81C784` para separar contenido sin ensuciar el diseño.
* **Espaciado:** Márgenes amplios entre secciones para potenciar la sensación de orden y limpieza.
